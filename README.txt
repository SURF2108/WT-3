ONLINE FOOD ORDERING SYSTEM
============================

Technology:
- React JS
- React Router
- CSS
- Vite

How to run:

1. Open this project folder in VS Code.
2. Open the terminal.
3. Run:
   npm install
4. Run:
   npm run dev
5. Open the localhost URL shown in the terminal.

Features:
- Home page
- Food menu
- Add food to cart
- Increase/decrease quantity
- Remove items
- Checkout form
- Place order

This is a simple frontend lab assignment.
